# Código de Conduta

Este projeto adota o Contributor Covenant v2.1 como código de conduta. Resumidamente:
- Seja respeitoso com as outras pessoas.
- Comunique-se de forma construtiva.
- Não toleramos assédio ou comportamento discriminatório.

Para reportar má conduta, contate o maintainer no perfil do GitHub ou abra uma issue privada.
