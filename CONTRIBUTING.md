Contributing to bip39-check

Obrigado pelo interesse em contribuir!

Guidelines (pt / en)
- Abra uma issue descrevendo o problema ou feature antes de enviar PR para discutir design e escopo.
- Crie uma branch com nome descritivo: `feature/<tema>` ou `fix/<tema>`.
- Execute: `cargo fmt --all` e `cargo clippy --all-targets --all-features -- -D warnings` antes de submeter PR.
- Inclua testes para novos comportamentos e casos de borda.
- Escreva mensagens de commit claras e atômicas.

Code style
- Siga as convenções do Rust (rustfmt, clippy).
- Documente funções públicas com doc-comments (///).

Issue e PR workflow
- Link a issue no PR (Ex: "Closes #12").
- Explique o que foi feito e por que no corpo do PR.
